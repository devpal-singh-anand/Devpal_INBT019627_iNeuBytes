## 📊 Task Breakdown

### Task 1 — SQL-Based Descriptive Analytics & Reporting
Loaded the Olist dataset into SQLite (9 tables, 52 columns) and ran descriptive/reporting queries.
- `analysis.sql` — all SQL queries
- `schema.md` — schema documentation
- `Task_1_Report.docx` — write-up with snapshots and video walkthroughs
- `Snapshots/`, `Video/` — supporting evidence

### Task 2 — Excel/Spreadsheet Analysis & Dashboarding
Cleaned raw data, built pivot tables, computed KPIs with formulas, and built an auto-updating dashboard.
- `Olist_Sales_Analysis_Dashboard.xlsx` — Raw Data → Cleaned Data → Data Cleaning Report → Pivot Analysis → KPI Scorecard → Dashboard
- `Task_2_Report.docx` — write-up
- `Snapshots/`, `Video/` — supporting evidence

### Task 3 — BI Dashboards (Power BI & Tableau)
Built interactive dashboards in both tools using an ETL pipeline (Extract → Transform → Load) and DAX/calculated measures.
- `Olist_Sales_Dashboard.pbix` — Power BI dashboard
- `Olist_Dashboard.twbx` — Tableau workbook
- `Task_3_Report.docx` — write-up
- `Snapshots powerbi/`, `Snapshots tableau/` — supporting evidence

### Task 4 — Data Storytelling & Stakeholder Communication
Translated findings into a stakeholder-facing narrative.
- **Key findings:** R$13.6M revenue across 96,478 orders · São Paulo = 38% of revenue · 91.9% on-time delivery (faster delivery correlates with better reviews) · 3.1% repeat purchase rate
- **Recommendation:** Diversify marketing, prioritize delivery performance, build retention programs
- `Task_4_Storytelling.pptx` — presentation deck
- `Task_4_Report.docx` — write-up

### Major Project — End-to-End Analytics Case Study
Capstone tying together SQL, Excel, Power BI, and Tableau into a single business case study on revenue concentration and customer satisfaction drivers.
- `Major_Project_Report.docx` — full case study
